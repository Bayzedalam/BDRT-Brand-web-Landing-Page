# BDRT Holdings — Homepage Concept

A responsive, single-page homepage concept based on the provided contest brief and visual reference.

## Files
- `index.html` — page structure and editable copy
- `style.css` — all styling, design tokens, type scale, desktop and mobile breakpoints
- `script.js` — mobile navigation, dynamic copyright year and restrained scroll reveals

## Preview locally
Open `index.html` in a modern browser. An internet connection is required for Google Fonts and the remote Unsplash photography.

## Quick editing guide
1. **Theme colours:** edit the CSS custom properties at the top of `style.css` (`--color-ink`, `--color-paper`, `--color-gold`).
2. **Typography:** edit `--font-body`, `--font-display`, `--text-*`, and `--heading-*` in `:root`.
3. **Section spacing:** edit `--section-space` and `--page-gutter`.
4. **Responsive layouts:** desktop defaults are followed by tablet/mobile breakpoints near the bottom of `style.css`.
5. **Photography:** replace each `images.unsplash.com` URL with approved existing brand photography or properly licensed stock photography. Images are remote stock-photo placeholders for the concept and should be reviewed/licensed before production use.
6. **Portals and business links:** Client Login and Donor Portal are intentionally non-functional navigation placeholders, as requested in the contest scope. Replace `#contact` with the real destination when supplied.
7. **Contact emails:** confirm the correct BDRT contact addresses before launch; the current `hello@bdrt.net` and `partnerships@bdrt.net` values are draft destinations.

## Design notes
- Luxury editorial direction: charcoal, warm ivory and muted champagne-gold.
- VOXA / VOXA House receive strong fashion-led imagery while the overall layout retains a holding-company identity.
- Business cards and project tiles are designed to scale as more ventures and portfolio projects are added.
- No AI-generated photography is included. The visual concept uses remote Unsplash stock imagery, which should be replaced or cleared for commercial use before production.
